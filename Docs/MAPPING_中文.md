# 三人映射与站位说明

状态：根据锁定 starter 与新工程配置编写的初始方案，真人验证待完成。姓名、个人选择理由和实测参数在排练后更新。队名与姓名见 `team.json`。

## 分工

| ID / 姓名 | 身体动作 | 大象部位或行为 | 中立姿态 | 初始参数与理由 |
|---|---|---|---|---|
| P1 / 待填 | 左右抬脚；左手上举或下放；躯干左右倾斜 | 左右前腿；前进、后退、跑步；转向 | 双脚着地，肩膀平稳，左手腰高 | 前腿每骨 -25°，灵敏度 1、平滑 8；行走与转向由同一人协调，减少互相抵消 |
| P2 / 待填 | 左右抬脚；躯干左右倾斜 | 左右后腿；尾巴摆动 | 双脚着地，身体直立 | 后腿 -25°、尾巴 30°，灵敏度 1、平滑 8；与 P1 口令配合形成前后肢节奏 |
| P3 / 待填 | 躯干倾斜；右手上下；双手展开或收拢 | 头部转向；鼻子卷曲；双耳 | 肩膀放松，右手腰高，手距舒适 | 头 25°，鼻 7 段各 12°，左右耳 +25° / -25°；灵敏度 1、平滑 8；负责表情及探查动作 |

这里的正负号是参考骨骼局部旋转方向，不是人体左/右的翻转开关。人体左右以表演者自己的身体为准；预览不做镜像。正式分工应写明本人为什么适合该角色，例如舒适的活动范围、节拍习惯或观察任务，不能把上述设计理由当作已调查的个人事实。

## 站位示意

```text
          非镜像摄像头预览中的位置
          [ P1 ]   [ P2 ]   [ P3 ]
           前腿     后腿      头鼻耳
           行走     尾巴
           转向
                  ↓ 全身可见
                 摄像头
                  ↓
 PoseLandmarker → 六个相对身体信号 → 校准 / 平滑 → 大象 rig
 ImageSegmenter → 人体轮廓 + 画面占比 → 摄像头预览
 Unity 模拟 → 合屏视频 + 轨迹 / 停留 CSV
```

相机正对团队；先以约 3-5 米距离试拍，再根据镜头调整，具体距离未实测。镜头保持水平，所有脚、髋、肩、手都要入镜。按预览画面的左到右建立 P1-P3；地面贴定位标记，留出不相互遮挡的间距。运行时不交换位置；附近其他人先退出画面。

## 校准、协调和输入冲突

P3 课程选择 3 / Upper body / Camera，点击十秒中立校准并保持不动。行走、转向灵敏度 1，死区 0.12，输入平滑 6；关键点最低置信度 0.5，失联阈值 0.5 秒。前腿、后腿的动作叠加权重为 0.35，底层行走动画负责基础步态；头、鼻、耳、尾权重为 1。这些值来自参考场景，尚未证明最适合本组。

P1 说“准备、走、停”，P2 跟节拍，P3 在全组慢速时展示局部动作。每个行为保持唯一明确的表演者；P1 的转向与 P3 的头部转向是独立通道。回到中立表示零偏移。多人 Camera 模式默认要求所有成员仍被追踪：任一角色丢失即停止行走/转向，持续检测到丢失达 0.5 秒后清除校准；完全无包时先经过 0.5 秒追踪超时再触发。单个脚部置信度下降但人物仍可见，不等于角色消失。校准提示会指出缺失的 P/动作。出现 RESET REQUIRED 或身份错配时停止移动，Reassign people 后重新校准。

## 保留与新增

保留：三人分工、六个姿态信号、中立校准、置信度检查、局部骨骼轴、步态叠加、跟随相机、合屏录制。选择它们是为了先得到可解释的共同控制基线；是否保留到最终表演，须以个人及集体测试为依据。

修复：角色分配在歧义或单人持续缺失超过 2 秒后锁定，重置前不自动恢复；三人初始人数必须准确，避免旁观者占槽位。导入的运行时脚本显式修复多人停止、校准诊断、遗漏槽位、自定义来源切换和上半身桥接启动参数；原 starter 源码保留。

新增：独立 MediaPipe ImageSegmenter，用官方 selfie 模型标记人体轮廓和画面占比，目标采样上限 5 Hz；它不分配身份，也不控制大象。添加 Unity 轨迹/停留记录器。只在首次创建的新演出场景把移动半径 15 改为 30 Unity 单位，使完整障碍场可达；参考场景与障碍场几何、种子 20261005 保留。

## 解释边界

这是人类代理驱动的行为模拟。人和大象的身体比例、关节、鼻子、步态及感知不同；平滑与步态动画也会改变动作。ImageSegmenter 的占比是像素统计，不是人的真实面积、距离或遮挡正确率。障碍场无碰撞器，轨迹或靠近地标的数据不等于真实碰撞和真实大象行为。
